# pclaf-bot

Bot interno de Telegram para consultas rapidas del panel PCLAF.

## Comandos

- `/resumen`
- `/espera`
- `/proceso`
- `/listo`
- `/canceladas`
- `/turno`
- `/turnos`
- `/descuentos`
- `/cliente texto`

## Secrets usados

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `TELEGRAM_WEBHOOK_SECRET`
- `SUPABASE_SERVICE_ROLE_KEY` o `SUPABASE_ANON_KEY`

`TELEGRAM_CHAT_ID` limita las respuestas al chat interno autorizado.
